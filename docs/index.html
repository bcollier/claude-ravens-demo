The test

Sixteen pictures and one missing square

?

Every row and column must contain each outer shape once and each bar pattern once. The bottom row already has a square with a horizontal bar and a circle with a cross, so the missing cell has to be an octagon with a vertical bar: option 3.

No words are involved — the test was designed in 1936 to measure reasoning without language. Eight sets of twelve run from 2×2 matrices up to 3×3 Challenge problems.

Architecture

Same sixteen images in, same one number out

Agent A

What the 2017 code was doing

Strip the plumbing and it is one idea applied seven ways: reduce each 184×184 panel to a single number, extrapolate that number along the row, the column and the diagonal, score each option by how close it lands, add the scores up with fixed weights, take the best. The measurements are ink coverage, shared ink between two panels, where the ink sits, an identity check, and a test for whether one panel is the pixel union of two others.

+

What was genuinely good

It compares relationships, not objects. The agent does not ask which option looks like H; it asks whether the H→option relationship matches the G→H relationship. That is analogy at the right level of abstraction, and it is not the obvious first thing to try. Rebuilt as a rule family in agent B, it earns one of the largest positive weights the ranker learns.

It eliminates as well as scores. If nothing in the matrix repeats, an option identical to a panel you can already see is probably a distractor. That is a constraint, not a score. Agent B carries the same signal and the fitted weight on it is large and negative — a model independently confirming a hand judgement from 2017.

It tests before it applies. Its union rule is checked on the rows you can see before being used on the row you cannot. That is the generate-and-test structure agent B uses everywhere.

−

What was missing

Representation. Every statistic collapses a panel to one number, so two panels with the same ink coverage are the same panel. An entire class of rule becomes literally inexpressible: the inner shape rotates while the outer frame stays put. Problem set D is built on exactly those rules.

No per-problem rule selection. The weights are constants. Every puzzle gets the same blend of measurements whether or not they apply. Nothing ever asks which rule is in force here?

Unfinished coverage. 2×2 problems return −1. Subtraction and intersection have weights reserved and are never written. Centroid and object count are computed in full, then multiplied by zero. Those are deadline fingerprints, and they cost 24 problems outright.

Its two real scoring bugs turn out not to matter. Fixed one at a time: 34, 34, 34. Fixed together: 33.

The weights had been hand-tuned by running the set and nudging numbers until the score rose, so the tuning had already absorbed the bugs. The typos were load-bearing.
Agent B

How a rule earns the right to vote

Agent B proposes a few hundred rules per puzzle. The hard part is not proposing them — it is working out which one the puzzle is actually about. So rules are scored the way you would score any predictor: hide something you already know the answer to, and see if the rule can recover it.

Why this was the thing to fix

Ten minutes spent measuring the ceiling redirected the whole project. The rule space almost always contains the right answer. The agent was not short of ideas; it was bad at picking between them.

Without that measurement the natural instinct was to add more rule types — which had just been tried, and had made the cross-validated score worse.

Agent C

What the language model is actually sent

Both views, in one request: the assembled sheet and every panel on its own. For a 3×3 problem that is 37 content blocks — 20 pieces of text and 17 images. The sheet carries the structure (which panels form a row, which cell is missing); a single cell inside it is far too small to compare shapes against. The individual panels carry the detail but lose every spatial relationship. Neither alone is enough.

Calibration

The LLM does not know when it is wrong

Every model was asked to return a confidence alongside its answer. gpt-5.6-sol averaged 0.99 on the problems it got right and 0.99 on the ones it got wrong.

There is no threshold you could set to catch its mistakes. If you were routing hard cases to a person, this signal would not find them.

Epilogue — added after class

Three things the session did not settle

Everything above ran live and is untouched. These were added afterwards, and the full write-up is in EPILOGUE.md.

1

A neural network, still no LLM

11/96

A relation network — a CNN plus a shared MLP over every pair of panels — trained only on synthetic matrices, so the real 96 stay a genuine held-out test. It lands at or below chance.

Two diagnostics explain why. Blanking every context panel drops it to chance, so it does read the matrix. But a bug in my generator left 18.6% of training problems with eight identical panels, whose answer was a copy of the context — and the network learned to prefer options that duplicate something already on the page. It does that on 29% of real problems, where that option is right only 10% of the time. A heuristic anti-correlated with truth is how a model gets below chance.

The symbolic agent learned the opposite sign on the same signal from real data: dup_max carries its largest negative weight.

2

A plain 70/30 split

62%

Stratified, 67 train / 29 test, over 20 seeds. Higher than the leave-one-set-out number above, because a random split lets the model see every problem family during training. The gap between the two is how much the agent depends on having met that kind of puzzle before.

The model weights were always held out. The feature design was not: set D's failures were inspected and rule families added because of them. No re-split fixes that.

3

Other labs

The in-class runs were all OpenAI. The epilogue adds one flagship vision model per lab on the identical prompt, with the dollar cost of every run. GPT-3.5 cannot be entered at all — it has no image input, so the barrier is modality, not reasoning.

Method

How to read these numbers

A

Everyone gets the same input

Panel images only. Two of the eight sets ship with a verbal description of each figure; the other six do not, so it is withheld from all three agents. The 2017 agent's author had already disabled that path anyway.

B

The learned part is cross-validated

Agent B trains on seven problem sets and is tested on the eighth, with every hyper-parameter chosen inside the training folds. Rule search with no training at all scores 49/96; scoring the ranker on the very problems it was fitted to gives 62/96, only 3 more — which is how you know it is learning which rules to trust rather than memorising answers.

C

The LLM score has an asterisk

These puzzles have been in a public GitHub repository since 2017. Contamination cannot be ruled out from here. Read it as a score on a public benchmark, not a clean measurement of novel visual reasoning. Agent B has no such exposure, which is part of why it is worth keeping.

D

They fail in different ways

The 2017 agent fails by declining. Agent B fails by picking a rule that fits but is not the rule — and it will name the rule it picked. The LLM fails confidently and leaves nothing to debug. Only the middle one explains itself.
